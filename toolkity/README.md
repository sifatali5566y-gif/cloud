# Toolkity - Free Online Tools & Utilities

A comprehensive collection of free online tools and utilities for developers, designers, and everyone. All tools work directly in your browser with 100% privacy - your data never leaves your device.

## 🌟 Features

- **20+ Professional Tools** - Comprehensive collection of frequently used utilities
- **100% Client-Side** - All processing happens in your browser
- **Privacy First** - Your data never leaves your device
- **No Registration** - Start using tools immediately
- **Mobile Friendly** - Fully responsive design for all devices
- **Fast & Lightweight** - Optimized for performance
- **Modern UI** - Clean and intuitive interface

## 🛠️ Available Tools

### Text Tools
- **Word Counter** - Count words, characters, sentences, paragraphs, and reading time
- **Case Converter** - Convert text to uppercase, lowercase, title case, sentence case, and more
- **Text Formatter** - Remove extra spaces, line breaks, add line numbers, and format text
- **Text Diff** - Compare two texts and find differences

### Image Tools
- **Image Resizer** - Resize images to custom dimensions with aspect ratio control
- **Image Compressor** - Compress images to reduce file size with quality control
- **Image Converter** - Convert between PNG, JPG, and WebP formats
- **Image Cropper** - Crop images with interactive selection

### Developer Tools
- **JSON Formatter** - Format, validate, and beautify JSON data
- **Base64 Encoder/Decoder** - Encode and decode Base64 strings
- **Hash Generator** - Generate MD5, SHA-1, and SHA-256 hashes
- **URL Encoder/Decoder** - Encode and decode URL strings
- **Color Picker** - Pick colors and get HEX, RGB, and HSL values

### Converter Tools
- **Unit Converter** - Convert length, weight, temperature, area, volume, and speed
- **Currency Converter** - Convert between different currencies (sample rates)
- **Number Base Converter** - Convert between binary, octal, decimal, and hexadecimal

### Calculators
- **Calculator** - Standard calculator with keyboard support
- **Date Calculator** - Calculate date differences and add/subtract days
- **Percentage Calculator** - Calculate percentages, increases, and decreases

## 🎯 Usage

Simply open `index.html` in a web browser to start using the tools. No installation or setup required. All tools are accessible from the homepage.

### For Developers

To customize or extend:
1. Clone or download the project
2. Modify `css/style.css` for styling changes
3. Add new tools in the `tools/` directory
4. Update `index.html` to link new tools
5. Use `js/main.js` for shared utilities
